# Dependencias según el motor

Un CSV por base, con el nombre exacto `<base>.csv` (`mod_rep.csv`, `strategos.csv`, …), resultado de
`sql/02-dependencias/<base>.sql`. Debe incluir la fila de encabezados. Separador coma, punto y coma o
tabulador; `NULL` se interpreta como vacío.

Solo contiene metadatos (nombres de objetos y columnas): nunca datos de las tablas.
